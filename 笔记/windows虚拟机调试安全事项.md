# 虚拟机调试恶意程序·安全准备速查表

| 风险项 | 等级 | 调试前操作 | 在哪关 | 不关的后果 |
|:---|:---|:---|:---|:---|
| **共享文件夹** | 🔴 极高 | **完全禁用** | VMware: 选项→共享文件夹→禁用<br>VBox: 设备→共享文件夹→删除全部 | 恶意软件直接读写宿主机文件，横向感染 |
| **剪贴板共享** | 🔴 高 | **禁用双向** | VMware: 选项→客户机隔离→取消勾选<br>VBox: 设备→共享剪贴板→禁用 | 敏感信息被窃取，恶意命令被粘贴回宿主机 |
| **拖拽功能** | 🔴 高 | **完全禁用** | VMware: 选项→客户机隔离→取消勾选<br>VBox: 设备→拖放→禁用 | 恶意文件通过拖拽触发宿主机漏洞（反向攻击） |
| **声卡** | 🟠 中 | **移除硬件** | 虚拟机设置→移除声卡 | 声卡驱动漏洞（如CVE-2020-3992）可导致逃逸 |
| **USB 控制器** | 🟠 中 | **移除硬件** | 虚拟机设置→移除USB控制器 | 恶意软件监控USB事件，感染宿主机U盘 |
| **打印机/串口/并口** | 🟡 低 | **全部移除** | 虚拟机设置→移除对应端口 | 老旧驱动存在未修复漏洞，增加攻击面 |
| **虚拟光驱** | 🟡 低 | **设置为无介质** | 虚拟机设置→光驱→无介质 | 若挂载了宿主机ISO，恶意软件可读取其中内容 |
| **VMware Tools 用户态服务** | 🟠 中 | **禁用相关服务** | `services.msc` → 禁用剪贴板/拖拽/音频/时间同步服务 | 同上，剪贴板/拖拽/时间同步被恶意利用 |
| **网络模式** | 🔴 极高 | **设为“仅主机模式”** | 虚拟机设置→网络适配器→仅主机模式 | 恶意软件联网下载载荷、攻击外网、回传数据 |
| **快照** | 🔴 极高 | **先拍快照再运行** | 虚拟机→拍摄快照 | 分析被污染后无法干净回滚，每次环境不一致 |


### 一句话核心
**在虚拟机里少一点便利，在现实中就少一次灾难。**
