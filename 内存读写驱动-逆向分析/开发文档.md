# rBv91EFp.sys 开发文档（简版）

> 驱动：`rBv91EFp.sys` ｜ 设备：`\\.\Cracker` ｜ I/O：`METHOD_BUFFERED` ｜ 指令码段：`0x238000~0x23804C`

---

## 1. 打开设备

```c
HANDLE h = CreateFileW(L"\\\\.\\Cracker", GENERIC_READ|GENERIC_WRITE, 0, NULL, OPEN_EXISTING, 0, NULL);
```

## 2. 调用协议

### SystemBuffer 布局（40 字节，5 个参数槽）

| 偏移 | 槽 | 常见用途 |
|---|---|---|
| +0x00 | arg0 | PID / 字符串指针 / 状态码输出 |
| +0x08 | arg1 | 地址 / 模块名指针 |
| +0x10 | arg2 | 长度 / 函数名指针 |
| +0x18 | arg3 | **输出指针**（基址、PID 写到这里） |
| +0x20 | arg4 | 方向标志 / 附加参数 |

### 调用骨架

```c
DeviceIoControl(h, code, &params, 40, &params, 40, &ret, NULL);
```

### 判错（两层，别混）

1. `DeviceIoControl` 返回 FALSE → 未知指令码/驱动异常。
2. 返回 TRUE 后读 `params.arg0`：
   - `0` = 成功
   - 非 0 = 业务错误码（见各指令）
3. **靠 arg3 输出的指令**：还要看 `*arg3` 是否为 0（0 = 没找到）。

> ⚠️ 关键：arg3 必须是**可写内存的地址**（如 `ctypes.addressof(result)`），传 0 会**蓝屏**（驱动执行 `*0 = 结果`）。

## 3. 指令码表

### 内存操作
| 码 | 功能 | 参数 | 错误码 |
|---|---|---|---|
| 0x238000 | 读写内存 (MmCopyVirtualMemory) | arg0=pid, arg1=目标地址, arg2=大小, arg3=本地缓冲, arg4=0读/非0写 | 0成功/1拷贝失败/2参数非法/3进程不存在 |
| 0x238004 | 读写内存 (MDL隐蔽版) | 同 0x238000 | 无（静默） |
| 0x238010 | 远程分配 (RWX) | arg0=pid, arg2=大小, arg3=输出基址 | 无（看*arg3） |
| 0x238014 | 远程释放 | arg0=pid, arg1=基址 | 无 |
| 0x238018 | 修改保护 | arg0=pid, arg1=地址, arg2=大小, arg3=输出旧保护, arg4=新保护 | 无 |

### 定位
| 码 | 功能 | 参数 | 错误码 |
|---|---|---|---|
| 0x23801C | **按进程名取PID** | arg0=进程名指针(char*), arg3=输出PID | 0成功(含未找到)/1内存不足 |
| 0x238008 | **按模块名取基址** | arg0=pid, arg1=模块名指针(char*), arg3=输出基址 | 无（看*arg3） |
| 0x23800C | 取导出函数地址 | arg0=pid, arg1=模块基址, arg2=函数名指针(char*), arg3=输出地址 | 无（函数名>4KB会FALSE） |

### 进程控制
| 码 | 功能 | 参数 | 错误码 |
|---|---|---|---|
| 0x238020 | 进程打标+缓存(死功能,疑似诱饵) | arg0=pid, arg4=0清+0x440并缓存/非0写标记到缓存进程 | 0成功/1状态冲突/2参数非法/3进程不存在 |
| 0x238024 | 终止进程 | arg0=pid | 无 |

### 注入与自毁
| 码 | 功能 | 参数 | 错误码 |
|---|---|---|---|
| 0x238048 | 远程创建线程（阻塞1秒） | arg0=pid, arg1=起始地址, arg2=参数 | 无 |
| 0x23804C | DLL注入 | arg0=pid, arg1=DLL路径(char*) | 0成功/1内部失败/2参数非法 |
| 0x238044 | 删除文件（含锁定） | arg0=文件路径(char*) | 无 |
| 0x238040 | 卸载驱动（自毁，最后用） | 无 | 无 |

## 4. 字符串铁律（0x23801C / 0x238008 重点）

- **必须单字节 `char[]`**（`create_string_buffer`），不能 `wchar_t*`（strlen 会被 `\x00` 截断）
- **必须传指针**（`addressof`），不是内容
- **必须是纯文件名**，不能带路径（如 `"HuntGame.exe"`、`"kernel32.dll"`）
- 大小写不敏感，ASCII 无编码问题；非 ASCII 按系统 ACP（中文系统=GBK）
- 输出槽 arg3 **必须传可写内存地址**，否则蓝屏

## 5. Python 参考

```python
def getPidByName(handle, name):
    nb = ctypes.create_string_buffer(name.encode('ascii'))
    result = ctypes.c_ulonglong(0)
    status, _ = deviceIoctl(handle, IOCTL_GET_PID_BY_NAME,
                            arg0=ctypes.addressof(nb),
                            arg3=ctypes.addressof(result))
    return status, result.value   # status==0 且 pid!=0 才算找到

def getModuleBase(handle, pid, name):
    nb = ctypes.create_string_buffer(name.encode('ascii'))
    result = ctypes.c_ulonglong(0)
    status, _ = deviceIoctl(handle, IOCTL_GET_MODULE_BASE,
                            arg0=pid,
                            arg1=ctypes.addressof(nb),
                            arg3=ctypes.addressof(result))
    return status, result.value
```
